# SynthFlag brand assets

The horizontal SynthFlag wordmark is the repository's canonical primary identity. It pairs four skewed cobalt signal bars with the SynthFlag name in Ink.

## Primary asset

| Asset | Status | Intended use |
|---|---|---|
| `synthflag-primary-wordmark.png` | **Primary** | Repository README, project pages, documentation headers, and wide brand placements |

Use this file whenever the full project identity should be visible. Keep its proportions intact, preserve the transparent background, and leave clear space around the complete lockup.

## Visual system

| Role | Color | Hex |
|---|---|---|
| Primary signal | Signal Cobalt | `#0040C1` |
| Primary type | Ink | `#111827` |
| Secondary type | Slate | `#4B5563` |
| Light field | Cloud | `#EFF4FF` |
| Divider | Line Blue | `#D1E0FF` |
| Highlight | Sky | `#6199FF` |

The four-bar geometry uses shorter outer bars and taller inner bars with consistent skew, spacing, and rounded ends. Do not stretch, rotate, rearrange, recolor individual bars, or place the wordmark on a visually busy field.

## Brand line

**SynthFlag — Evidence before certainty.**
