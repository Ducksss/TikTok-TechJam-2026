# SynthFlag brand explorations

A 60-asset working system for the SynthFlag identity, built from the four skewed signal bars, Signal Cobalt, Ink, Cloud, and an evidence-first editorial voice.

> These are exploration assets, not fabricated product results. Metric and dataset templates intentionally leave values blank until real evidence is available.

> **Technical-story boundary:** asset `51-four-experts-diagram.png` is a
> historical V1/V2 exploration and does not show the selected TEST1 runtime.

## Usage notes

- Keep the four-bar geometry intact: shorter outer bars, taller inner bars, consistent skew and spacing.
- Treat scores as probabilities with context, not verdicts.
- Pair any metric with its dataset, split, threshold or operating point, sample count, and uncertainty.
- Prefer calm editorial layouts over generic “AI” motifs such as neon circuitry, robot imagery, eyes, brains, shields, or fabricated dashboards.
